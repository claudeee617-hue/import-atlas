# Changelog

## [0.1.0] - 2026-11-07

### Added
- Scan Python, JavaScript/TypeScript and Go and resolve imports between files.
- Single-file, offline, interactive HTML map: force layout, search, zoom/pan, click-to-inspect,
  colour by folder / role / language, dark and light themes, PNG export.
- "Start here" list, circular import detection (Tarjan SCC), PageRank-based importance.
- CLI: `--open`, `--json`, `--exclude`, `--max-nodes`, `--fail-on-cycles`.
